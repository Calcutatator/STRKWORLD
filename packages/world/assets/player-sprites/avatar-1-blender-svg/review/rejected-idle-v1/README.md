# Rejected idle-v1

James rejected this draft as cursed and insufficiently close to the approved
concept. The full source, SVGs, PNGs and original evidence are preserved in
commit `110b26e517e4e4236a1a867e6482945e2482bb93`. This directory preserves the
presented review image and subsequent rejection. It is not an art source.

Previous internal visual QA was too permissive: it checked generic coherence
and a local eye correction, without requiring reference fidelity. Mechanical
export checks did pass, but did not establish artistic acceptance. Failures
included hair silhouette, heavy outline, weak eyes, rigid legs/boots and an
oversized protruding profile buckle.
