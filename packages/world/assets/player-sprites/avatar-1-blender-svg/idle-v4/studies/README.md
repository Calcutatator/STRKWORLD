# Internal construction references and discarded studies

The only approved concept is `../../concept/avatar-1-concept-v2.png`.
None of the files in this directory is approved concept art or a user-approved
in-game sprite.

`front-construction-v1.png` was generated using that concept as its reference.
It retained the character's pose and outfit but contained too much fine detail
for 64-pixel cells. Its sampling/grid previews failed internal review because
facial features were lost. The filename `front-sampled-24.png` describes an
attempted quantization, not a validated 24-colour result; that failed study is
not used by the active construction or export.

`front-construction-v2.png` is an ImageGen edit requesting much larger, simpler
pixel clusters. `coarse-turnaround-construction-v1.png` was generated using
both the approved concept and front construction-v2. The original generated
references, exact prompts and provenance are retained here. Their proportions
and faces require deliberate registration/refinement in the editable design.

`*-grid.png` and grid review sheets are internal construction previews.
Final review uses only PNGs under `../frames/`, derived from native Blender SVG
exports. No sampling preview should be labelled a final Blender result.
